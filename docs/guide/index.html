🚀 快速开始

Java 17+ 与 Maven 即可运行，整个过程大约 3 分钟。

1. 环境要求

  • ✅ Java 17+（推荐 21）
  • ✅ Maven 3.8+
  • ✅ 可选：ripgrep（grep_code 优先使用，未安装自动回退）
  • 🔑 至少一个 API Key：GLM_API_KEY / DEEPSEEK_API_KEY / STEP_API_KEY / KIMI_API_KEY / FREELLMAPI_API_KEY / XFYUN_MAAS_API_KEY / AGNES_API_KEY

2. 构建与运行

# 1. 配置 API Key（.env 已被 gitignore，不会上传）
cp .env.example .env

# 2. 构建（默认跳过测试，优先产出可手工验收 jar）
mvn clean package

# 3. 运行
java -jar target/yicli-1.0-SNAPSHOT.jar

# 4. 环境体检（可选）
yicli doctor

3. 第一次对话

* /model glm-5.1          # 切换模型（默认按配置）
* /doctor                # 检查 Java / ripgrep / API Key / 数据目录
* 帮我读 README.md 并总结核心架构
* /hitl on               # 开启危险操作人工审批（可选）
* /exit

🛡️ 安全模型

本地 Agent 默认不做容器/VM 沙箱，安全模型是 HITL + 路径校验 + 命令黑名单 + 审计四层。

🚧

PathGuard

文件类工具路径强制限定在项目根内，拦截绝对路径逃逸、.. 穿越与符号链接逃逸。

⛔

CommandGuard

命令黑名单 fast-fail：sudo、rm -rf 全盘、mkfs、dd of=/dev、fork bomb、curl|sh 等。

👀

HITL 审批

write_file / execute_command / create_project / revert_turn / 所有 MCP 工具默认走审批；审批框已做 ANSI 注入清洗，可配超时。

🔑

权限记忆

批准过的调用按 (tool, 参数) 精确匹配记入 ~/.yicli/permissions.json，跨会话免打扰；全部放行有次数上限。

📋

审计脱敏

JSONL 审计按天落盘；write_file 不记 content 正文，MCP 参数按字段名掩码 token/key/secret。

🚫

无头默认拒绝

微信 / Runtime API / 后台任务没有审批面板，走非交互默认拒绝：只读放行，写入拒绝敏感文件（.env / *.pem / id_rsa 等）。

🔌 扩展与生态

YiCLI 的扩展面是声明式的：知识用 Skill，工具用 MCP，行为用 Prompt 覆盖，生命周期用事件总线。

✍️ 接入自己的 MCP server

# ~/.yicli/mcp.json 或项目 .yicli/mcp.json（项目级按 server 名覆盖）
{
  "mcpServers": {
    "my-server": {
      "command": "npx",
      "args": ["-y", "my-mcp-server"],
      "env": { "TOKEN": "${MY_TOKEN}" }
    }
  }
}

启动后自动注册为 mcp__my-server__* 工具；${VAR} 支持环境变量 / 系统属性 / .env。

📦 Skill：把专家手册打包给模型

每个 Skill 是一个目录：SKILL.md（决策手册）+ references/（按需读取）。加载位置：jar 内置 < 用户级 ~/.yicli/skills/ < 项目级 .yicli/skills/。

* /skill list
* /skill show web-access
* /skill on my-skill      # 模型看到匹配描述时自动 load_skill

🔁 会话与恢复

退出自动保存会话；取消或 LLM 失败自动留检查点。换终端、关电脑都不丢上下文。

* /sessions
* /resume session_1722600000000_1
